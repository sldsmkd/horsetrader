# TN-0001 — Strongest Team becomes Dream Team

## Status

**Open — ETL source changes started; bundle and planner handoff remain.**

Use this runbook to carry the official Global name **Dream Team**, its generic
EN banner, and the corrected first-event schedule through the complete
ETL-to-planner path.

This is a presentation correction, not a new event type. Preserve every stable,
persisted, and procedural identifier already used for Strongest Team.

## Trigger

The first Global occurrence exposed three pieces of previously unavailable
truth:

- The official EN name is **Dream Team**, replacing the provisional
  **Aim! Strongest Team** translation.
- Cygames publishes an official generic EN header:
  <https://assets-webview-umamusume-en.akamaized.net/contents/assets/images/uploads/Header/banner_30900001_L1782338400.png>
- The event launched with the June 25, 2026 content beat. The generic date
  mapper had placed it one day late on June 26.

The June 25 beat was strongly corroborated: both gacha banners and
`main-story-07` mapped their shared JP launch of July 20, 2022 to June 25, 2026.
`strongestteam-001` began one JP day later, on July 21, and the uncorrected
mapper carried that offset into Global even though the actual event joined the
same content drop.

## Identity contract

Do **not** perform a mechanical Strongest Team → Dream Team rename. The old
tokens are established identifiers, not display copy.

| Layer | Keep | Reason |
| --- | --- | --- |
| Event discriminator | `strongestteam` | Baked wire contract and UI routing |
| Stable keys | `strongestteam-NNN` | Event identity and saved references |
| Python model names | `StrongestTeam`, `StrongestTeams` | Internal API; no migration value |
| Config keys | `strongest-team` | Reward structure/map lookup |
| Play-style setting | `strongestTeam` | Persisted user document compatibility |
| Stream id | `play.strongest-team` | Engine attribution and engagement vocabulary |
| Display name | **Dream Team** | Official Global name; change everywhere visible |
| Generic image | `/img/misc/dream-team.webp` | Official EN art; new path avoids stale cache reuse |

Changing any identifier in the first six rows requires a separately designed
migration. TN-0001 does not authorize one.
