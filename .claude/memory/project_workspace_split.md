The earlier ETL/web **workspace split was reversed on 2026-06-01** into a single **monorepo** rooted at `/home/kris/code/horsetrader/`. The ETL half was moved up to the root, so the repo root now *is* the Python backend (its `.git` is the monorepo's):

- Repo **root = the ETL backend**. Python package at `horsetrader/`, docs at `docs/`, curated source data at `config/` (tracked).
- `horsetrader.site/` — the front end (JS/CSS now, aseprite icons later), a **tracked subtree** of the monorepo (its short-lived sub-repo was deleted 2026-06-01); only its `node_modules/` / `.wrangler/` are gitignored. Named to sit right next to `horsetrader/` in the tree ([[project_site_consumer_workspace]]).
- `static/` — the **deploy artifact**, gitignored & regenerated by the build pipeline ([[project_build_pipeline]]). (The old `generated/` bake-handoff dir was removed entirely 2026-06-01.)
- `_horsetrader.old/` — legacy port-source, still **ignore entirely** (don't read/grep/reference; the user ports across by hand).

Gitignored: `static/` (deploy artifact), `.cache/`, `venv/`, `_horsetrader.old/`, and the frontend's `node_modules/` / `.wrangler/`. Everything else — including the `horsetrader.site/` source — is tracked in the one repo.

**Why:** The multi-root VSCode workspaces (each `.code-workspace` cross-referenced siblings) were confusing and bloated sessions. Consolidating to one folder fixes the human side. The *separation* the user still wants is now enforced as **workflow discipline**, not a filesystem boundary — partly hygiene, partly to stop sessions ballooning past his weekly token budget.

**How to apply:**
- A session is **single-purpose**. Backend work happens at the root / in `horsetrader/`.
- **Crossing the backend↔site line is the smell.** If you find yourself about to edit both the backend and `horsetrader.site/` in one session, STOP and warn loudly — it means we're ranging too far and should be a fresh, separate session. Don't quietly keep going.
- Default file/grep searches to the backend tree; filter out `_horsetrader.old/` hits and don't wander into `horsetrader.site/`/`static/` unless that's explicitly the task.
